# Settings

Campos relevantes:
- `validar_entrega_total` (Check, default 1)
- `validar_pago_total` (Check, default 1)
- `tolerancia_pago_monetaria` (Currency, default 0)
- `requerir_persona_comision` (Check, default 1)
- `aplicar_reduccion_por_diferimiento` (Check)
- `fecha_base_reduccion` (Select: Due/Posting Date…)
- `politica_margen_negativo` (Select: CERO / NEGATIVO_COMPENSA / REQUIERE_APROBACION)
- `permitir_negativo_solo_si_margen_original` (Check)
- `avisar_negativo_en_ui` (Check)
- `permitir_total_orden_negativo` (Check, default 0)

Notas: cambios requieren `Save` en el Single.
